# Формат результата

## 1. Что поправить первым

5–7 пунктов, по убыванию влияния на доверие/конверсию. Каждый — одна строка: что не так → что сделать →
куда идти в интерфейсе.

```
1. Headline — список из трёх ролей через «|», непонятно, к кому из трёх обращаться. Выбрать один подход
   (роль и компания / роль | для кого | доказательство) под стартовый сегмент ICP.
2. About начинается со ссылки и приветствия, боль клиента или результат появляются только после «see more».
   Первые 2–3 строки — боль или результат, приветствие и ссылку — ниже.
3. Featured пуст. Добавить гайд/пост/вебинар: свой профиль → кнопка «Add section» → Featured.
4. Рекомендаций нет. Запросить у 2–3 ЛПР с готовым текстом: зайти на профиль ЛПР → «More» → Request a
   recommendation (либо со своего профиля, в блоке Recommendations — «Ask for a recommendation»).
5. ...
```

## 2. Статусы чек-листа вкладки «Профиль»

Ровно девять строк, по названию — не по номеру. Значения: `готово` / `не готово (что сделать)` /
`неприменимо (почему)` / `не проверено с профиля — см. как проверить`.

| Строка чек-листа | Статус |
|---|---|
| Красивый URL профиля | |
| Фото и баннер | |
| Featured (витрина под лид-магнит или кейс) | |
| Опыт переписан результатами | |
| Запрошены 3 рекомендации от ЛПР | |
| Личная верификация | |
| Верификация компании | |
| Open Profile включён | |
| Язык профиля = язык рынка | |

Если есть доступ к таблице участника — эти значения идут не в отчёт, а прямо в ячейки вкладки «Профиль»,
блок «ЧЕК-ЛИСТ РАЗДЕЛОВ», колонка «Статус», подбором строки по тексту. В отчёте тогда — одна строка
подтверждения («статусы внесены во вкладку «Профиль»») и сама таблица для проверки глазами.

## 3. Разбор headline и About

**Headline сейчас:** «...» (дословно). Подход: роль-и-компания / роль-для кого-доказательство / ни то ни
другое. Что не работает: 2–3 пункта.

**About сейчас:** первые 2–3 строки дословно + что дальше по структуре (боль → решение → доказательства →
CTA, что из этого есть, а чего нет). Что не работает: 2–3 пункта. CTA: один или несколько, какие именно.

Без вариантов замены — только диагноз. За текстом: промпт «Копирайтер профиля».

## 4. Не проверено с профиля

Список того, что не проверяется со своего профиля (обычно все три: главная кнопка, Open Profile,
публичность) + путь самопроверки по каждому, из `references/linkedin-howto.md`.

Признаки халтуры: «профиль в целом неплохой, но можно улучшить» без единого дословного примера; статус
чек-листа без указания, что делать при «не готово»; headline/About переписаны заново вместо диагноза;
пункты приоритетного списка не привязаны к конкретному месту в интерфейсе.

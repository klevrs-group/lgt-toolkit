# Формат результата

## 1. Значения для листа ICP

**Фильтры Sales Navigator** (одна ячейка, две строки):
```
Leads: Current job title: … | Seniority: … | Company headcount: … | Industry: … | Geography: … | Profile language: … (или «не ставим») | Keywords: (… OR "…") NOT …
Accounts: Industry: … | Headcount: … | HQ: … | Keywords: …
```

**Ёмкость** (одна ячейка):
```
По Sales Navigator (дата): N лидов по фильтрам; N₂ с Profile language: <язык> (или без); account-поиск N₃
компаний; пересечение лидов и account-листа N₄. Вердикт: подтверждён / расширить до ~1 000 (чем) / резать (чем)
```

## 2. Десять профилей

| # | Должность (как в профиле) | Компания, штат | Живой? (активность 90 дн) | Подходит под ICP? | Почему нет |
|---|---|---|---|---|---|

Итог: подходят N из 10. Если меньше 6 — фильтр ловит не тех, вернуться к шагу 1, а не расширять.

## 3. Вердикт и расширение

- Базовый поиск: N. С языком / без: N₂. Пересечение: N₄.
- Порог: 1 000 (или заданный).
- Что сделали для расширения (один параметр): …, стало N₅. Проверка десяти профилей после расширения: подходят M из 10.
- Что предлагаем пользователю: …

## 4. Сохранённые поиски

- «LGT · <сегмент> · leads» — дата, N.
- «LGT · <сегмент> · accounts» — дата, N₃.
Напоминание пользователю: раз в неделю открыть сохранённый поиск, LinkedIn покажет «+N новых».
